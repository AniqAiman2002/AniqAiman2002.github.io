Pengangkutan & Aksesibiliti

Destinasi di Petaling, Gombak dan Klang mudah diakses menggunakan LRT, MRT, dan KTM Komuter. Untuk ke Sekinchan, Kuala Selangor atau Hulu Selangor, memandu sendiri atau menyewa kereta adalah pilihan terbaik.

Masa Terbaik Melawat

Untuk melihat Sawah Padi Sekinchan menghijau atau menguning, datang sekitar bulan Mac–Mei atau September–November. Bagi Sky Mirror, semak jadual air surut (hari bulan gelap/purnama).

Tempahan Tiket Awal

Tarikan popular seperti SplashMania Gamuda Cove, Sunway Lagoon, dan bot Sky Mirror sering penuh pada hujung minggu dan cuti sekolah. Tempah tiket secara dalam talian sekurang-kurangnya 3 hari awal.

Etika Pakaian & Keselamatan

Sediakan pakaian sopan ketika melawat rumah ibadat seperti Masjid Biru Shah Alam dan Batu Caves. Bawa losyen pelindung matahari dan penghalau nyamuk apabila mengunjungi kawasan paya bakau atau kelip-kelip.

Cara Simpan & Host Website di GitHub Pages

Muat turun fail HTML atau ikut langkah mudah di bawah untuk terbitkan laman web anda secara percuma.

Fail Laman Web Lengkap (`index.html`)

Semua kod HTML, penggayaan CSS (Tailwind), dan fungsi JavaScript telah digabungkan dengan kemas di dalam satu fail supaya anda mudah memuat naiknya ke GitHub tanpa masalah pautan rosak.

Langkah Demi Langkah Muat Naik ke GitHub:

1. Buat Repository Baru

Log masuk ke akaun GitHub.com anda. Klik butang "+" (New Repository). Namakan sebagai explore-selangor dan pilih Public.

2. Muat Naik Fail `index.html`

Klik butang "Add file" → "Upload files". Tarik fail index.html yang anda muat turun tadi dan klik "Commit changes".

3. Aktifkan GitHub Pages

Pergi ke tab Settings → Pages (di menu kiri). Di bawah bahagian Branch, tukarkan daripada None kepada main dan klik Save.

4. Laman Web Anda Sedia! 🎉

Tunggu sekitar 1-2 minit. Pautan rasmi website anda seperti https://nama-anda.github.io/explore-selangor/ boleh terus dikongsi!
