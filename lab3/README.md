# Homestay Indah (Astrum Sena, Seksyen 14, Shah Alam)
Laman web rasmi bagi Homestay Indah berketinggian kondominium moden di Seksyen 14, Shah Alam. 
Menawarkan pemandangan penuh bandaraya Shah Alam, mempunyai 3 bilik tidur dan 3 bilik air (disewakan untuk keseluruhan unit).

## Cara Pasang ke GitHub Pages (github.io):
1. Buka akaun [GitHub](https://github.com) dan cipta satu repository baharu (contohnya: `homestay-indah` atau `<username>.github.io`).
2. Muat naik (Upload) semua fail di dalam folder ini (pastikan `index.html` berada di root direktori utama).
3. Masuk ke tab **Settings** di repository GitHub anda.
4. Klik pada menu **Pages** di sebelah kiri.
5. Di bahagian **Branch**, pilih `main` (atau `master`) dan folder `/ (root)`, kemudian klik **Save**.
6. Tunggu 1-2 minit, laman web anda akan terus aktif secara langsung di alamat: `https://<username>.github.io/<repo-name>/`.

Fail `assets/audio/muzik_ceria.mp3` ialah melodi ceria asli (bebas hak cipta) yang dimainkan berulang. Pelayar menyekat bunyi automatik, jadi ia bermula pada klik/ketik pertama pelawat. Butang "Muzik" di penjuru kiri bawah untuk hidup/matikan; pilihan diingati antara halaman.
